# Conduit test-scaffold

A Conduit component for test-scaffold functionality

## Installation

```bash
# Via Conduit component system
conduit components install test-scaffold

# Via Composer (if published)
composer require jordanpartridge/conduit-test-scaffold
```

## Commands

- `conduit init`

## Usage

```bash
# Example usage
conduit init --help
```

## Development

```bash
# Install dependencies
composer install

# Run tests
./vendor/bin/pest

# Code formatting
./vendor/bin/pint

# Static analysis
./vendor/bin/phpstan analyze
```
